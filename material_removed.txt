\section{Old part}
The estimation of the time-varying impedance require the system to be perturbed with a multi-sine waveform and record input and output synchronously. Most commercial potentiostats-galvanostats do not have the implementation for user-defined arbitrary waveform on the computer user interface to be transferred on the instrument hardware and when a workaround is possible (i.e. ...) the number of points of the multi-sine and the maximum frequency are limited. Usually the buffer memory for the digital-to-analog converter of FPGA boards is a value between 12 kSa and 32 kSa according to my experience browsing manufacturers catalogs, which translates to a multi-sine of ??? decades. Furthermore the maximum frequency of sampling, which defines the maximum recordable tone according to the Nyquist-Shannon theorem, is quite limited due to the difficulty of transferring  big amount of data from the instrument to the computer. The maximum sampling frequency for a premium device might be in the order of 50 kHz. For most electrochemical systems the impedance is informative over 5 or more decades and to frequency up to 1MHz. On the other hand, commercial potentiostats-galvanostats have high precision electronics, with tested circuit boards that allow very small and high current and voltage ranges. The approach used in this work is to integrate a commercial arbitrary waveform generator and a high performance signal acquisition device to a potentiostat/galvanostat exploiting its input and output ports and avoiding the need of designing a high power circuit from scratch. In a nutshell, the set-up we used is composed of an arbitrary waveform generator which applies a custom waveform that define the experiment on the potentiostat though an auxiliary imput. The signal from the cell is recorded on the computer by the digital acquisition device though the auxiliary current and voltage ouput of the potentiostat which sends directly the anaolg signal of the cell. The data are later processed on the computer using custom software.
In the following the parts of the set-up will be better explained, as well as the connection between the devices.

\subsection{Digital acquisition device}

The acquisition stage of the set-up must satisfy two requirements:
\begin{itemize}
    \item Sampling at frequency of the order of MHz,
    \item Sample very long signals of hundreds of thousands of points.
\end{itemize}
Many solutions are available on the market to easily achieve these goals. They mainly fold into two categories base on their connection: USB or PCI. For this work we chose to use a USB device which satisfies all the requirements while being relatively inexpensive. USB devices are practical and portable and it is possible to connect many of them on the same computer. The devices chosen are from the PicoScope digital computer oscilloscope from Pico Technology. The devices can interface with a computer through the proprietary software PicoScope Software or the feature-rich software development kit available in multiple programming languages directly from the manufacturer GitHub page (\url{https://github.com/picotech}). Pico Technologies sells different series of devices with different capabilities. In this work we used 
\begin{itemize}
    \item PicoScope 4824A (4000A series) with 8 channles and a resolution of 12bit,
    \item PicoScope 4262 (4000 series) with 2 channles and a resolution of 16bit,
    \item PicoScope 5442D (5000 seires) with 4 channels and a resolution of 16-15-14 or lower bit depending on the number of channels active.
\end{itemize}
For the concerns of this work, the main differences between the devicea are
\begin{itemize}
    \item the number of channels,
    \item the resolution of the analog-to-digital converter expressed in bit (higher number is better, as discussed in \ref{sec:ADC})
    \item the maximum sampling frequency (which is always fare above the needs in electrochemistry),
    \item the cutting frequency of an internal filter low-pass filter.
\end{itemize}
The peculiar characteristics of these devices is the \emph{streaming mode} for transferring continuous acquisition of signals without loss even when the signal is longer than the device memory (other modes are available such as block mode and ???). 
The software development kit (SDK) from the manifacturer provides an interface to the USB drivers to conveniently include the streaming of data into the user program. The streaming mode works as follow: the user defines in their program a memory segment and a function to execute some actions on the data which are bidden to the software and when some new data is ready, the USB drive automatically writes the new numbers in the memory segment and calls the function (which is commonly referred to as callback function). In the callback the data in the memory segment should be processed, saved or evaluated in some way because will be overwritten in the next call anyway.
The routine runs in a infinite \lstinline[language=Python]{while} loop.
A common approach, and also the suggestion from the manual, is to have another memory segment in the user program, let's call it \emph{signal storage} for clarity despite being save on the RAM volatile memory and not in the permanent disk, large as much as the signal to sample where to copy the new data at each execution of the callback. The manual from the manufacturer gives a lot of information on the streaming mode and how to set it up. Code examples are also available for each supported programming language.

The data streamed are the numbers coming from the digitization step and they need to be converted before using them. The conversion factor depends on the resolution of the devices used (see \ref{sec:ADC}).

The most streighforward to handle the streaming data is to keep in memory all the data coming from the devices and then save the data to storage. This is the approach used also for this work at the beginning. The limitation is the actual RAM memory installed in the computer in use. A standard office computer with 16 GB of RAM might be sufficient to store the complete voltage and current signals for short measurements. The duration of such experiment would depend on the aquisition frequency. The ammount of points that can be usually stored in 16GB is 900.000.000 per channel which correspond to ?? GB . The memory occupied by the operating system and other application has to be taken into account. For example, when acquiring at 5MHz with the PicoScope the acquisition lasts 180 seconds while at 5KHz 50 hours. The first case should apply for studying electrode reactions during voltage sweep technique as for the study of hydrogen evolution on catalysts while the second for the study of battery degradation in galvanostatic mode. 50 hours is still a short time when compared to Li-ion batteries that it in the order of month. To measure the impedance for such long time one might decide to periodically store data into the computer hard-drive freeing up the memory or acquiring the signals not for every cycle. This ideas will be further development in a later paragraph.




\section{Connecting cells in three-electrode configuration}
Collecting the time-varying impedance of both positive and negative electrode of a three-electrode cells together requires some considerations. The potentiostats/galvanostats have usually only two auxiliary analog outputs: voltage versus reference and current. Furthermore, in any technique, the device controls the voltage difference between working and reference terminal. It effects either chrono-amperometric techniques because the counter as traditional for electrochemistry is only there to complete the circuit and chrono-potentiometric were despite the controlled counter being the same in the entire cell, it is not always possible to control the full cell voltage as it is not output in analog signal. Biologic devices are capable of changing the voltage control from working electrode vs reference to working vs counter through the hardware configuration section of the software EC-Lab. Unfortunatly this is not implemented in the EC-Lab SDK version ?? and one must come up with alternative, creative solutions. The easiest workaround is to employ two channels of the potentiostat, both in two electrode configuration with on to controll the techniques between working and counter electrode and the other between working and reference electrode to record the voltage drop in the half cell in OCV technique. 
Using just one channel of the instrument in three-electrode configuration and measure the voltage between working and counter (the full cell volage) with the digital aquisition device doesn't allow the controll of the full cell voltage, which is crucial for batteries, and connecting the instrument in two electrode configuraion connecting working and counter and recoridng the voltage drop between working and reference is not a good practice because the imput impedace of the PicoScope is just of 10 MOhm, one order of magniuted less than a potentiostat, that would cause a big bias current flowing on the referenece drifting it out of the quasi-thermodynamic equilibrium that would have instead.

The filtered signal was then resampled at 50Hz for storing. \\
The remaining part of the spectra from 10mHz to 0.8Hz was estimated offline using the Dynamic Multi-frequency Analysis with again a symmetric Fermi-Dirac filter centered at each frequency to analyze. The bandwidth is of 0.01Hz, the order of 8. Perform performing the analysis, both voltage and current signals were detrended using a simple linear baseline removal to reduce the effect of the drift.

\subsection{regression of rational polynomial}

colorbox{BurntOrange}{Despite begin so challenging to measure the impedance of a system, especially in non-stationary condition, it is only half of the job. To make all the work worth, one must extract information about the system under study.}

A transfer function, as is the impedance, is in its analytical form a rational polynomial as shown in the introduction. After estimating the impedance spectrum of a system over a set of frequencies from an experiment, it comes natural to want to deduct the transfer function that output such results to be used as model of the system and simulate it behavior under different operating conditions than the experiment. For this work we combined some ideas from statistics and system theory to find in a robust approach to find such function among the many possible. The first idea is to have a generalized model of additive terms, i.e. polynomial, as from the Generalized Additive Models but non linear and especially both rational and of incremental power. This translates in a model of such a form:
\begin{equation}
    f(x) = \frac{a_0+a_1x+a_2x^2+...+a_kx^k}{b_0+a_1x+b_2x^2+...+b_kx^k}
\end{equation}

This is identical to the definition of transfer function. It is convenient to fix b0 to 1 to have always a finite value. The second idea come from Information theory and it is about the choice of an opportune k which means to have a criteria to decide when to stop adding term to the polynomial. In fact, a fitting gets always “better”, or the residues of the regression are smaller, with the increase of the number of parameters. On the other hand the new parameters have no physical significance or do not univocal define the system. In this case we talk about overparametrization. The problem of estimating the original information from a signal with uncertainty is at the core of a branch of statistics and Computer science called Information Theory. The amount of information, translated in common means as degree of freedom of a system, is converted to a quantity called Entropy of information. Minimizing this quantity brings to the correct number degrees of freedom for a model to describe the data. This concept was formalized by Akaike and further developed in the years. 

When searching for the correct transfer function model for the case of time-varying systems it is also expected that the coefficients (a and b) of the rational function continuously change during the evolution of the system physiacal chacartesitics without any sudden jump or going to zero. This scenario can very when the model is overparametrized in certain parts of the dataset (for example at the beginning or at the end of the experiment). In fact the parameters space of the fitting procedure becaome rougher with many close minima. The solution might not anymore be unique. Thi is clear when fitting the single impedance spectra from a time-varying experiment one after the other. To ensure smoothness and continouity of the fitting parameters, a penalty factor can be added to the object function of the minimization.  For this work we used a penalty on the second derivative of the parameters and this means adding one non-free paraemeter on the function. The choice of this parameter has of course a great influence on shape of the costa function hyper-surface and so the minimization procedure. A value too big don’t allow the parameters to vary until exactly fitting them while a value too small make the penalty negligible. The objective function to minimize in now the sum of the residues for the fit of all the spectra in the dataset analysed (i.e. the time-varying impedance of one discharge) plus the penalty factor. The problem defined this way has a very high dimensionality and could not be solved with standard solver for its uge memory consuption. For this projecy I use once again the library pymultipleis that take advantage of JAX virtual mapping to split the problem in smaller problems and efficiently parallelize it on the machinne. Furthermore the autodifferentiation capabilities reduce the compution time. \colorbox{BurntOrange}{The working principles of the library are described extensivelly in the introduction.}
\colorbox{Green}{The fitting of the model where conducted } on the admittance using the modulus as weighting factor. This helps the convergence to the absolute minimum giving less importance to the lower frequency that carry higher uncertainty.
To decide over the correct model and penalty factor value for an opportune model, I compared the different information criterium values of multiple optimization run in which I screened the rational function of increasing order k and eight smoothing factors for each, one value per decade from 1e-6 to 1e4. I repeated the regression for each of the four cells and the results are summarized in figure XX.

\subsection{The origin of the chemical potential}

It is then important to understand the origin of the chemical potential from a foundamental perspective. This is particularly useful when describing the electrochemical potential of battery materials. From a materials science or inorganic chemistry perspective, the chemical potential at room temperature correspond to the fermi level of the electrones in the solid, hence the distance from the latest occupied atomic orbit and the void state (where the electrone is not bounded).
The Fermi level depends on the class of material. For metals, the situation is quite simple because the electrons can occupy any energy from a continous band. For semiconductors and insulators this is not true. A gap of unaccsesible energy levels is found, known as band gap. Depending on the material composition and strucutre, the band gap can be different leading to a different chemical potential and hence the electrochemical potential of the electrochemical cell were said material is used. When designing useful electrochemical device, the scientist put a lot of effort on the design of materials with certain properties. The description of the electronic structure, also known as density of states, is an hard task and require to solve big system of equations. The Density Functional Theory allow to semplify the calculation under certain conditions and led to a new reserach field of computation material science discovery, altough it is not matter of this thesis to dive deeper into it. 

Electrochemistry first developed studying redox reaction of metals in aqueous electrolytic solutions. \subsection{Measuring the electrochemical potential}

It is clear already how improtant is the direct measurement of the electrochemical potential for a specific electrode. Unfortunatly it is impossible to get this value from direct measurement. In fact, the simplest electrochemical cells is made of two electrodes and ehnce we can only get a voltage difference. One can get the electrochemical potential of an electrode under study if the second electrode in the cell has a known electrochemical potential. For this task has been developed specific electrode that can deliver such properties called "reference electrodes". The most known reference is the standard hydrogen electrodes made of a platinum electrode immersed in a sulforic acid solution at the temperature of 25 degrees in which pure hydrogen is bubbled at the pressure of 1 atm giving a solution of unitary fugacity. This set-up is reproducible which lead to the decision of using it as a reference point. The electrochemical potential of all the metals are measured in respect to this value and it is referred to "standard reduction potential" (standard beacuase standard conditions) and it is the value used in the nerst equation.

The standard hydrogen electrode, unfortunalty precents some practical shortcoming mostly due to the handling and storage of the flammable hydrogen gas. For the everyday labowork, simpler and safer electrodes are used. Exemples are the calomel electrode and the silver/silver chloride. The latter being the standard in every lab. These electrodes are not as stable and reproducible as the standard hydrogen electrode but they are easilly to prepare and handle and present a quasi-stable electrochemical potential when well maintained. 

It is interesting to consider the case of silver/silver chloride beacuse offer an example of a quasi-reference electrode. Silver is complittly surrounded by silver cloride between which an equilibrium redox reaction is present. Such electrode is immersed in a superconcetrated solution of KCl (3M) in order to have enough Cl ions to not change the coposition of the AgCl. The whole semi-cell is incpsulate into a glass container which terminates with a glass fret to allow the passage of ion.

It is sometimes forgotten that to measure any voltage a small quantity of current has to flow, in fact the electrochemical potential is the measure of work needed to move the electrode from its orbital. This leads to some redox reaction to happen, altering the surface morfology of the electrode as well as concentrations of the solution which alters the electrochemical potential.

One can even think of putting silver directly in contact with a solution containing silver ions, even in direct contact with the electrode of which measuring one is interested of measuring the potential. In principle, this type of configuration can be used as reference electrode, but it has to be granted a constant concentration of silver ion and absence of other ions that might alter the silver redox. This type of reference electrodes are called pseudo-reference electrode and altough much more prone to drift, they might be the only possible solution for certain cell configuration, especially when introducing them in real working devices.

Other issues of secondary reference electrodes might be the interference of the redox reaction at the reference electrode of ions coming from the other electrodes (known as poisoning) or the other way around, where the components of the reference electrode are interfering with the other part of the cell. 

Note: in general the cell is considered to be divide in two semi-cell. Each semi-cell is in ionic contact and have their own electrode. A salt bridge help to keep separated the electrolyte of the two.


\section{Kinetics}

Up to this moment, I only covered the case of systems at the equilibrium which represent an interesting case for study the principles of electrode potential and electromotive force but lacks the decription of the effect of the current on the double layer. This aspects are particularly important in applications as for example corrosion of metals, anodization, energy strorage in batteries and electrocatalisys.

When a current flows though the poles of a cell, the double layer at each electrodes is altered because of the change of concentration of ions. What happens is an increase (oxidation) or deplition (reduction) of ions at the interface which alters the double layer capacitance. A change in the latter modifies the electrical field which is reduces or increase in respect to the equilibrium value. This difference is referred to as over-potential or under-potential (potential can be swapped with voltage when there is no reference electrode in the cell). The over- or under-potential is stronger the higher is the current, beacuse the faster is the chemical kinetics of the reaction and hence the amount of ion produced or depleted at the interface. The amount of over- under- potential depends on how fast new ions are brought towordes the surface when depleted or moved out the surface when generated, a behaviour that depends on the diffusivity and mobility of the charged species. This effect can be easily notices when sweeping the voltage applied to an electrochemical cell from the equilibrium value to above. There is a zone where the current is small enough that only the redox reaction is the limiting factor while the ions are moved in or out the surface fast enough to not change the concentration. On the end of the curve the diffusivity of the ions become the rate determining step. In the middle there is a gray zone.

\subsection{Double layer structure}

Since the electrode is a conductor, it can in first principles considered to behave like an ideal resistor. In fact, early experiments showed that imposing a direct current trough two electrode (that makes up an electrochemical cell) produces a certain voltage difference betweens the poles. It follows that the voltage measured is produced by the electrochemical work or Gibb's free energy of the chemical reaction. To be precise, the voltage difference between the electrode correspond to the different in free energy between the redox reaction of the two electrodes, which means that no voltage difference is produce when the two electrodes are of the same chemical nature. One of the first historical examples of electrochemical cell is the pile of Alessandro Volta made of zinc and copper put immersed in an electrolyte solution. 

This leads to the second empirical quantity of early electrochemsitry which is the electromotive force of a cell. The electromotive force integrate in time gives the electrochemical work of the cell.

This simple models though falls short when imposing an alternate current at the cell terminal. In fact, using the language of electrotechnics, the phase of the current get shifted that means there is a beaviour similar to an ideal capacitor present in the circuit. To be precise, the capacitor has been demostrated to be in parallel with the resistor, making up the so called RC circuit; more on this later. The presence of a capacitor in the model means that there is a separation of charge at the interface between the redox active material and the electrolyte phase. Different models were proposed to represent the properties of such capacitive interphase:
- the Stern model
- Helmoltz-Perrin
- the Guy-Chapman model
The most recent model describes the interphase as composed by different layers (from here the name electrical Double-layer): 
- asdorbed ions
- gradient of concentration made of two parts
-- the diffused where the electric field is not zero (then the bulk starts) and migration takes place
-- the diffusion layer where the gradient of ion concentration cause diffusion from the bulk to the surface of the electro-active material.
The most important take on the existance of a capacity double layer is that the voltage difference across the intrerphase is not anymore just the Gibbs free energy of reaction but there is also a component of electrostatic interaction between charges and the electrical field. In other words, the voltage difference between the two terminals is the difference between the electrochemical potential. A quantity made of the sum of chemical potential and electrical potential acting to the species.
A note on terminology: the word electrode is often vague and used to describe the electro-active material only or the current collector but here is used to indicate the threedimensional region of space in which the electrochemical reaction takes place, as for IUPAC convention.

\section{Electrochemical methods}
This chapter described the foundamentals principles behind electrochemistry and about battery technology. 
The electrohemical methods are devided in two big families, direct current method and alternate current method. The first family deals with applying a voltage or a current and observing the other witht time. Also in this case we can make a distinction between constant perturbation method or sweeping methods. In the first case the control is kept constant in time, this methods are known as galvanostatic and potentiostatic. The constant perturbation can be also stepped from zero to the value to zero again (pulsed) or continou to increase in constant increments as a stiarcase. In the latter falls the method of polarization experiment used in certain fields. This class of experiment is used in corrosion, electrodeposition and battery characterazion, more on this later. The other type of method instead involve the sweep of the control quantity, which means a constant increase in time with fiexed ratio. This is a very thypcal experiment done from early days of electrochemistry to explore windows of potential and find the electrochemical potential value for an analytes. It is common to sweep the voltage in both directions and this is known as cyclic voltammetry. Voltammetry is used for characterizing HOMO and LUMO of molecules as well as sensing and qualitative analysis of chemicals in solution. \\
The second family of methods is based on alternating current. As mentioned before, the method is crucial to caracterize capacitive behaviour in the electrode. The most common technique under this family the Electrochemical Impedance Spectroscopy. The peculiarity of it is to apply an alternating voltage or current (sinus wave) at difference frequency to the electrochemical cell and measure the output. The output will have a change in amplitude, following Ohm's Law, as well as phase. The change in amplitude and phase is a characteristic of the electrode and can be thought as a unique fingerprint. Using alternate methods at different frequencies allows to capture the kinetics of different processes and to quantify the resistance. This topic is divulged in the next section of the chapter.

\subsection{Three electrode cells}
Taking back the concept of reference electrodes introduced before, it is now important a precisation for the case of measurment outside the thermodynamical equilibrium. In fact, reference electrodes should stay at equilibrium and they acceppt only small current though them (order of pA) for the sick of probing the voltage. If one is interested of measuring the potential of an electrode when a bigger current is flown, an auxiliray electrode is needed. This electrode has the role of closing the electrical circuit between the electrode under study, called workin electrode) for the flow of current. At the same time a second high-impedance circuit is used to measure the voltage difference between the working electrode and the refernce electrode. This gives also experimental access to the over-potential generated by the current.\\
The position of the reference electrode in a three-electrode set-up is quite important. Consider that between working and auxiliary electrodes current is flowing in the form of flux of ions. The movement of charged particles generate an alectomagnetic field which alters the local electric field. This means that the double layer of the reference electrode might be altered and shift the electrochemical potential of the electrode. It is then raccomended to place the reference electrode far from the current lines. Furthermore, it is not wise to put the reference electrode too far beacase of the longer path for the ionic current between working and reference electrode. A longer path produces an ohmic drop in the measure voltage difference which also alters read out voltage. The voltage drop due to the placement of the reference electrode is called "I-R drop", and can be corrected though alternate current methods. Modern electrochemistry device have the feature to perform an I-R drop compensation automatically, but it is generally better to place the reference electrode as close as possible to the working electrode, still not in the middle of current lines.

The resistor is the simplest ideal element. The voltage applied to it is linearly related to the current and no phase shift is happening. The linear relationship is defined with the Ohm's law
$$
V = R I
$$
with the resistance $R$ as proportionality factor, measured in Ohm. When an alternating current is appliead, the same relationship holds so the impedance $Z$ is equal to the $R$.

\subsubsection{Capacitor}

The ideal capacitor is a device constitute by a two paralle conductive plate separate by an insulator. When current flows in the circuit, the charges accumulates on the plate untile the voltage between them is equal but opposite to the voltage applied to the circuit. The behaviour of a capacitor under constant current is then dynamic. The plates charges for a certain caracteristic time that depends on the current applied and then no more current flows, behaving like an open circuit. 

When an alternating current is appliead to a capacitor, the voltage produced has a phase shift of 90° and no current flowing. The mathematical expression of the impedance for an ideal capacitor is then:
$$
Z = -\frac{1}{j\omega C}
$$
Where $C$ is the capacitance.

\section{Battery management systems (BMS)}

The battery management system (BMS) is the supervisory electronic unit responsible for monitoring, controlling and protecting a battery pack during operation. A battery pack is a connection of batteries in series or parallel combined to obtain a certain power output. The BMS plays a critical role in ensuring safety, maximizing performance, extending lifetime and providing accurate estimates of internal states that cannot be measured directly.

\subsection{Core functions of a BMS}

The principal functions of a BMS include:
\begin{itemize}
    \item \textbf{Voltage measurement and protection:} maintaining all cells within their safe operating voltage window.
    \item \textbf{Current monitoring and control:} enforcing charge/discharge current limits to avoid thermal runaway or lithium plating.
    \item \textbf{Temperature monitoring:} collecting data from multiple sensors and controlling the thermal management system.
    \item \textbf{State estimation:} estimating state of charge (SOC), state of health (SOH), state of power (SOP) and internal resistance.
    \item \textbf{Cell balancing:} equalizing charge among cells to avoid imbalance and premature degradation.
    \item \textbf{Communication:} interfacing with vehicle control units or stationary system controllers.
\end{itemize}

\subsection{State estimation}

SOC estimation typically combines coulomb counting, OCV lookup tables and equivalent-circuit models. SOH estimation often relies on capacity fade tracking or increases in resistance. However, these traditional methods face challenges under dynamic load profiles or aging-related drift.

Model-based estimation methods integrate electrochemical models or pseudo-two-dimensional (P2D) models to increase accuracy. Kalman filters, particle filters and machine-learning methods are widely used in modern BMS implementations.

\subsection{Impedance-based diagnostics}

Electrochemical impedance contains rich information on reaction kinetics, SEI resistance, charge-transfer processes, concentration gradients and diffusion limitations. Therefore, impedance is a powerful tool for BMS diagnostics.

However, conventional frequency-sweep EIS is too slow for embedded systems. Modern research explores:
\begin{itemize}
    \item on-board fast EIS using multisine or perturb-and-observe techniques,
    \item online impedance tracking during dynamic driving cycles,
    \item data-driven impedance models to estimate SOC and SOH.
\end{itemize}

This thesis contributes to this direction by developing instrumentation for continuous impedance measurement using multisine excitation under galvanostatic cycling. The goal is to extract time-varying parametric transfer functions for predictive SOH estimation. The long-term perspective is to integrate such impedance-based diagnostics into a ``smart BMS'' capable of adaptive control and health prediction at cell level.



\section{Local linearisation and small-signal approximation}

Impedance spectroscopy assumes that the applied perturbation is sufficiently small so that the system behaviour is well approximated by a linear model around an operating point. Let $(x_0,u_0)$ be a steady-state or slowly varying operating point such that
\begin{equation}
f(x_0,u_0)=0.
\end{equation}
Define perturbations $\delta x=x-x_0$ and $\delta u=u-u_0$. Expanding $f$ and $g$ to first order yields
\begin{equation}
\dot{\delta x}(t) = A\,\delta x(t) + B\,\delta u(t), \qquad \delta y(t) = C\,\delta x(t) + D\,\delta u(t),
\end{equation}
with Jacobian matrices
\begin{equation}
A=\frac{\partial f}{\partial x}\Bigg|_{(x_0,u_0)},\quad B=\frac{\partial f}{\partial u}\Bigg|_{(x_0,u_0)},\quad C=\frac{\partial g}{\partial x}\Bigg|_{(x_0,u_0)},\quad D=\frac{\partial g}{\partial u}\Bigg|_{(x_0,u_0)}.
\end{equation}
This LTI system is called the small-signal model. Its validity requires that the amplitude of the perturbation is small enough that higher-order nonlinearities are negligible and that the operating point remains effectively constant over the period of excitation.

\subsection{Validity of LTI approximation for drifting systems}

Real electrochemical systems exhibit slow drift due to side reactions, temperature changes or consumption/production of species. Let the true system be
\begin{equation}
\dot{x}(t)=f(x(t),u(t),t).
\end{equation}
A frozen-time LTI approximation is valid over a time window $[t_0-\Delta t/2,\,t_0+\Delta t/2]$ if the drift timescale $T_{\text{drift}}$ satisfies
\begin{equation}
T_{\text{drift}} \gg T_{\text{excitation}},
\end{equation}
where $T_{\text{excitation}}$ is the period of the highest frequency in the perturbation. Under this condition the system can be treated as LTI in each short window, justifying the extraction of a local transfer function $G(t_0,s)$.

\section{From electrochemical PDEs to linear models}

Electrochemical behaviour is governed by nonlinear PDEs. Examples include mass transport in the electrolyte,
\begin{equation}
\frac{\partial c}{\partial t} = D\nabla^2 c - \nabla \cdot (uc),
\end{equation}
solid-state diffusion in active material particles,
\begin{equation}
\frac{\partial c_s}{\partial t} = D_s \nabla^2 c_s,
\end{equation}
and charge-transfer kinetics described by the Butler--Volmer equation. Linearising these equations around an operating point yields linear PDEs with linearised boundary conditions. For example, the linearisation of Butler--Volmer gives
\begin{equation}
\delta j = \frac{1}{R_{\mathrm{ct}}}\,\delta \eta + C_{\mathrm{dl}}\,\frac{d}{dt}\delta \eta,
\end{equation}
where $R_{\mathrm{ct}}$ is the charge-transfer resistance and $C_{\mathrm{dl}}$ the double-layer capacitance. The result is a distributed linear system whose frequency response corresponds to the impedance of the electrode.

\section{Transfer functions and rational polynomial models}

Applying the Laplace transform to the linearised model yields the transfer function
\begin{equation}
G(s)=C(sI-A)^{-1}B+D.
\end{equation}
This is a rational function of $s$:
\begin{equation}
G(s)=\frac{b_0 + b_1 s + \cdots + b_m s^m}{a_0 + a_1 s + \cdots + a_n s^n},
\end{equation}
with poles determined by the eigenvalues of $A$ and zeros determined by $(A,B,C,D)$. Diffusion processes may yield terms of the form $Z(s)\sim 1/\sqrt{s}$ (semi-infinite Warburg), which can be approximated by rational polynomials (Padé approximation) or represented as fractional-order elements.

\section{Kramers--Kronig relations and their role in impedance}

The Kramers--Kronig (KK) relations follow from the principles of linearity, causality and stability of LTI systems. A causal LTI system has a transfer function $G(j\omega)$ that is analytic in the upper half of the complex frequency plane. As a result, its real and imaginary parts are Hilbert transforms of each other:
\begin{equation}
\Re[G(j\omega)] = \frac{1}{\pi}\,\mathcal{P}\!\!\int_{-\infty}^{\infty} \frac{\Im[G(j\omega')]}{\omega' - \omega}\, d\omega', \qquad \Im[G(j\omega)] = -\frac{1}{\pi}\,\mathcal{P}\!\!\int_{-\infty}^{\infty} \frac{\Re[G(j\omega')]}{\omega' - \omega}\, d\omega'.
\end{equation}
These integral relations imply that the real and imaginary parts of a physically meaningful impedance spectrum cannot be chosen independently: one completely determines the other. Therefore, KK relations provide a fundamental \emph{consistency check} for measured impedance data.

In practice, KK tests are used to assess whether an impedance dataset satisfies the assumptions of:  
(1) linearity of response,  
(2) stationarity of the system during measurement, and  
(3) causality of the underlying dynamics.  
Significant deviations from KK consistency typically indicate violations of these assumptions, often due to nonlinearity (perturbation too large), drift (system not LTI during measurement), or experimental artefacts (e.g., incorrect current/voltage synchronization). For systems with slow drift, KK compliance may only hold approximately within short time windows, aligning with the frozen-time approximation.

\section{Identification of time-varying systems: general principles}

A slowly drifting system can be modelled as a linear time-varying system in which the transfer function evolves as
\begin{equation}
G(s,t) = C(t)(sI-A(t))^{-1}B(t) + D(t).
\end{equation}
Identifying such systems generally relies on windowed estimation: within each short interval the system is approximated as LTI, and the corresponding transfer function or parameter set is estimated independently. The temporal evolution of the poles, zeros or parameters then describes the drift of the system. Although detailed techniques for impedance-based identification are discussed in the next chapter, the present framework provides the theoretical justification for treating an electrochemical system as locally LTI and for representing its behaviour through rational transfer functions.

\section{Dynamic systems: inputs, outputs and states}

A dynamical system is any physical or engineered system whose output evolves in time in response
to external stimuli. Mathematically, we distinguish three fundamental objects:
\begin{itemize}
    \item the \emph{input} $u(t)$, representing external actions (e.g.\ applied current or voltage),
    \item the \emph{output} $y(t)$, the measurable system response,
    \item the \emph{state} $x(t)$, the minimal set of internal variables needed to determine future behaviour given the past inputs.
\end{itemize}

A precise input--state--output description enables classification of three key structural properties.

\subsection{Causality}
A system is \emph{causal} if the output at time $t$ depends only on inputs applied at times $\tau \le t$,
never on future values. All physical electrochemical systems are causal, and this property is essential for prediction, control and real-time estimation.

\subsection{Linearity}
A system is \emph{linear} if it satisfies the superposition principle: for any scalars $\alpha,\beta$,
\[
    u_1 \to y_1,\quad u_2 \to y_2
    \quad\Rightarrow\quad
    \alpha u_1 + \beta u_2 \to \alpha y_1 + \beta y_2.
\]
Electrochemical cells are not globally linear: Butler--Volmer kinetics, concentration-dependent transport
coefficients and side-reactions are nonlinear. However, for sufficiently small perturbations around an
operating point, the system admits a linearized representation. This \emph{local linearity} underpins 
electrochemical impedance spectroscopy (EIS) and all small-signal identification techniques.

\subsection{Time invariance}
A system is \emph{time invariant} if its characteristics do not change with time. Formally, for any delay
$\tau$,
\[
    u(t) \to y(t)
    \quad\Rightarrow\quad
    u(t-\tau) \to y(t-\tau).
\]
A time-invariant system exhibits shift-symmetry and admits a representation via convolution and the
Fourier transform. Real batteries, however, drift with state-of-charge, temperature and ageing, so they
are inherently \emph{time varying}. In practice, one assumes that over sufficiently short time windows the
system is \emph{locally time invariant}, enabling classical frequency-domain identification.

\section{Physical modelling: ODEs, PDEs and linearization}

\subsection{Lumped-parameter models (ODEs)}
If spatial variations can be neglected, the system can be represented by an ordinary differential equation
(ODE):
\[
    \dot{x}(t) = f(x(t),u(t),t),
\]
with output $y(t)=g(x(t),u(t),t)$. This framework captures charge-transfer kinetics, double-layer charging,
thermal balance and other lumped processes commonly used in equivalent-circuit modelling.

\subsection{Distributed-parameter models (PDEs)}
Electrochemical systems frequently exhibit spatial gradients of concentration and potential. Mass transport in electrodes and electrolyte is governed by partial differential equations (PDEs), e.g.\ diffusion:
\[
    \frac{\partial c}{\partial t} = -\nabla\!\cdot J + R(c,\varphi,t),
\qquad J = -D\nabla c.
\]
These PDE models require boundary conditions and generally cannot be solved analytically; after spatial
discretization (finite difference, finite element, method of lines) they reduce to high-dimensional ODEs.

\subsection{Fractional-order behaviour}
Porous electrodes and multi-scale diffusion often produce responses governed not by integer-order
differentiation but by fractional derivatives. This leads to impedances with power-law frequency
dependence, such as constant-phase elements (CPEs). Fractional models arise naturally from 
solution of diffusion PDEs on fractal or heterogeneous domains.

\subsection{Linearization and small-signal modelling}

Let the full nonlinear model be
\[
    \dot{x} = f(x,u), \qquad y=g(x,u).
\]
Choose an operating point $(x_0,u_0)$ and define perturbations $\tilde{x}=x-x_0$, $\tilde{u}=u-u_0$,
$\tilde{y}=y-y_0$. A first-order Taylor expansion yields
\[
    \dot{\tilde{x}} = A \tilde{x} + B \tilde{u}, \qquad
    \tilde{y} = C \tilde{x} + D \tilde{u},
\]
where $A,B,C,D$ are Jacobians evaluated at the operating point. This \emph{linear time-invariant} (LTI)
approximation forms the basis of impedance modelling and transfer-function identification.

\subsection{From electrochemical PDEs to rational transfer functions}

After linearization, applying the Laplace transform converts temporal derivatives to algebraic multiplication by $s$, yielding
\[
    (sI - A)\tilde{X}(s) = B \tilde{U}(s).
\]
The input--output relation is
\[
    \tilde{Y}(s) = H(s)\tilde{U}(s), \qquad H(s)=C(sI-A)^{-1}B + D.
\]
If the underlying system arises from discretization of a PDE (e.g., diffusion), the transfer function may 
contain non-rational terms such as $\sqrt{s}$, leading to Warburg-type impedances. For practical
identification and BMS implementation, one approximates these functions via rational polynomials
(e.g.\ Padé expansions, finite-length RC ladders). This provides the theoretical justification for using
equivalent circuits and rational transfer functions to approximate distributed electrochemical dynamics.

\section{Modelling paradigms}

Depending on the level of mechanistic detail and data availability, models fall into three categories:

\subsection{White-box models}
Derived entirely from first principles (mass balance, charge conservation, diffusion, kinetics). They offer
high physical interpretability but require many parameters and expensive computation.

\subsection{Grey-box models}
Embed simplified physical structure (e.g.\ RC networks, Randles circuits, diffusion ladders) but estimate
several parameters from data. These are the standard approach for EIS and BMS-oriented modelling.

\subsection{Black-box models}
Purely data-driven (ARX/ARMAX, transfer-function fitting, neural networks). They can approximate
complex dynamics but provide little mechanistic insight.

The choice depends on the balance between physical interpretability, computational cost and the
precision required for the intended application.

\section{Transfer functions}

\subsection{Laplace transform and algebraic representation}

Consider an $n$th-order ODE:
\[
a_n y^{(n)}(t)+\cdots+a_1 \dot{y}(t) + a_0 y(t)
=
b_m u^{(m)}(t)+\cdots+b_1 \dot{u}(t) + b_0 u(t).
\]
Applying the Laplace transform under zero initial conditions yields
\[
Y(s)\,(a_0 + a_1 s + \cdots + a_n s^n)
=
U(s)\,(b_0 + b_1 s + \cdots + b_m s^m).
\]
The \emph{transfer function} is the ratio
\[
H(s)=\frac{Y(s)}{U(s)}
=\frac{b_0 + b_1 s + \cdots + b_m s^m}{a_0 + a_1 s + \cdots + a_n s^n}.
\]

\subsection{Frequency response}
Setting $s=j\omega$ gives the frequency response $H(j\omega)$, whose magnitude and phase describe the
gain and phase shift of each sinusoidal component. For electrochemical systems,
\[
Z(\omega)=\frac{U(\omega)}{I(\omega)}
\]
is the impedance and $Y(\omega)=1/Z(\omega)$ the admittance.

\subsection{Poles and zeros}
Roots of the numerator of $H(s)$ are zeros; roots of the denominator are poles. Poles determine the
system modes and stability, while zeros shape attenuation and resonance. In discretized systems, the
$z$-transform plays an analogous role with $H(z)=Y(z)/U(z)$.

\section{Kramers--Kronig relations}

For any linear, causal and stable system, the real and imaginary parts of its frequency response are not independent: they are linked by the Kramers--Kronig (KK) relations. These follow directly from two physical principles:

\begin{itemize}
    \item \textbf{Causality}: the impulse response $h(t)$ vanishes for $t<0$,
    \item \textbf{Linearity \& stability}: the Fourier transform $\int h(t)e^{-j\omega t}dt$ exists and is analytic in the upper half-plane.
\end{itemize}

Let $H(\omega)=H'(\omega)+jH''(\omega)$ be the frequency response. Then the KK relations are
\begin{align}
H'(\omega) &= \frac{1}{\pi}\,\mathrm{P.V.} \int_{-\infty}^{\infty}
\frac{H''(\omega')}{\omega'-\omega}\,d\omega', \\
H''(\omega) &= -\frac{1}{\pi}\,\mathrm{P.V.} \int_{-\infty}^{\infty}
\frac{H'(\omega')}{\omega'-\omega}\,d\omega'.
\end{align}

For electrochemical impedance, $Z(\omega)=Z'(\omega)+jZ''(\omega)$ must satisfy KK if it originates from a passive, causal and time-invariant system. Violations indicate:
\begin{itemize}
    \item nonlinearity (amplitude too large),
    \item drift or non-stationarity (SoC or temperature changes during measurement),
    \item instrumentation artefacts or noise,
    \item insufficient frequency range or resolution.
\end{itemize}

KK validation is thus a crucial diagnostic tool for confirming that experimental data reflect a true LTI impedance and that subsequent parameter identification (e.g.\ equivalent-circuit fitting) is meaningful.

\section{Time-domain response}

\subsection{Impulse and step responses}

The impulse response $h(t)$ characterizes any LTI system via convolution:
\[
y(t) = \int_0^\infty h(\tau)\,u(t-\tau)\,d\tau.
\]
In practice an exact Dirac impulse cannot be generated; instead short current or voltage pulses approximate a broadband excitation.

The step response $y_s(t)$,
\[
y_s(t)=\int_0^\infty h(\tau)\,d\tau,
\]
captures cumulative effects such as charge accumulation (double-layer charging), adsorption, and diffusion.

\subsection{Modal decomposition}

If the system has poles $p_i=\sigma_i\pm j\omega_i$, the impulse response decomposes into
\[
h(t) = \sum_i \alpha_i e^{p_i t},
\]
where $\sigma_i$ sets the decay rate and $\omega_i$ the oscillatory frequency. Electrochemical cells typically exhibit:
\begin{enumerate}
    \item an instantaneous ohmic drop,
    \item one or more exponential decays due to charge-transfer resistance and double-layer (or adsorption) capacitances,
    \item a long-time $\sqrt{t}$ diffusion regime.
\end{enumerate}

This structure explains why simple RC circuits capture early-time behaviour, while diffusion effects dominate at longer times.

\subsection{Broadband time-domain excitations}

Pulses, chirps, multi-sines and pseudo-random binary sequences (PRBS) provide broadband excitation. Deconvolution or cross-correlation methods may recover an estimate of $h(t)$, though noise amplification and overlapping time constants make frequency-domain methods more robust in practice.

\section{Frequency-domain response}

\subsection{Definition}

The frequency response (or impedance) is the ratio of output to input Fourier transforms:
\[
H(\omega)=\frac{Y(\omega)}{U(\omega)}.
\]
For electrochemical systems:
\[
Z(\omega)=\frac{U(\omega)}{I(\omega)}, \qquad 
Y(\omega)=\frac{1}{Z(\omega)}.
\]

\subsection{From FRF to transfer function}

The frequency response function (FRF) is the practical estimate of $H(j\omega)$ from experimental data:
\[
\hat{H}(\omega)=\frac{\hat{Y}(\omega)}{\hat{U}(\omega)}.
\]
If the system is LTI and measurements are noise-limited rather than drift-limited, $\hat{H}(\omega)$ approximates the true transfer function evaluated along the imaginary axis.

\subsection{Steady-state sinusoidal stimulation}

Sine-wave excitation at individual frequencies produces high-SNR measurements with simple interpretation of amplitude and phase. This is the basis of classical stepped-sine EIS.

\subsection{Broadband excitation}

Chirps, multi-sines and PRBS signals accelerate experimentation by stimulating multiple frequencies simultaneously. Multi-sines are widely used in battery research because they concentrate signal power at selected frequencies, improving SNR without requiring more measurement time.

\section{Digital signal processing essentials}

This section reviews the DSP concepts required for computing FRFs, estimating impedance and analysing non-stationary behaviour.

\subsection{Sampling and quantization}

Any digital measurement system samples a continuous signal $x(t)$ at discrete times $t=nT_s$, producing $x[n]$. The sampling frequency $f_s=1/T_s$ must satisfy the Nyquist--Shannon criterion:
\[
f_s \ge 2 f_{\max},
\]
where $f_{\max}$ is the highest frequency component present in the signal. Undersampling leads to aliasing, which corrupts spectral estimates. Anti-aliasing filters remove components above $f_s/2$ prior to sampling.

The analog-to-digital converter (ADC) also introduces quantization noise, affecting low-amplitude measurements typical in high-frequency EIS.

\subsection{Discrete Fourier Transform (DFT) and FFT}

The DFT of a sequence $x[n]$ is
\[
X[k]=\sum_{n=0}^{N-1} x[n] e^{-j2\pi kn/N}.
\]
The Fast Fourier Transform (FFT) computes $X[k]$ with complexity $O(N\log N)$, enabling real-time spectral analysis.

In impedance experiments one often does not need the full spectrum; the Goertzel algorithm efficiently evaluates the DFT only at specific frequencies and is particularly attractive for embedded hardware or BMS integration.

\subsection{Spectral leakage and windowing}

If the sampled signal does not contain an integer number of cycles of the excited frequency, the DFT spreads power into adjacent spectral bins—\emph{spectral leakage}. Window functions (Hann, Hamming, Blackman, etc.) taper the signal to reduce leakage at the cost of widening the main lobe and reducing frequency resolution.

For multi-sine or chirp experiments, proper windowing is essential to minimize bias in FRF estimates.

\subsection{Noise, SNR and averaging}

Noise is incoherent while the system response is coherent. Averaging $M$ repeated measurements improves SNR by $\sqrt{M}$. In the frequency domain, Welch averaging reduces variance in spectral estimates. Increasing the record length (reducing the FFT bin width) also lowers noise power per bin.

\subsection{Short-time Fourier Transform (STFT)}

To analyse drifting or time-varying systems one applies the STFT:
\[
X(m,k)=\sum_{n=0}^{N-1} x[n+mR]\, w[n]\, e^{-j2\pi kn/N},
\]
where $m$ indexes time windows and $w[n]$ is a window function.  
The STFT reveals how the spectral content evolves in time and provides the foundation for non-stationary impedance estimation discussed in later chapters.

\subsection{Digital-to-analog synthesis (DDS)}

Perturbation signals are generated digitally and converted to analog form via a digital-to-analog converter (DAC). Direct digital synthesis (DDS) uses a lookup table and phase accumulator to produce high-purity sine waves or arbitrary waveforms. Synchronization between DAC and ADC clocks is crucial to avoid phase drift and spectral leakage in FRF estimation.

\section{Excitation signals}

The choice of excitation determines which system dynamics are activated, how the frequency response function is estimated, how long the experiment lasts, and how robustly parameters can be identified. For electrochemical systems, one generally seeks a perturbation small enough to guarantee linearity while maintaining a sufficiently high signal-to-noise ratio. The four most common excitation families are:

\begin{itemize}
    \item \textbf{Single sine waves} (stepped-sine EIS): only one frequency is injected at a time, giving maximum SNR and straightforward interpretation of gain and phase. This is the classical approach for high-precision impedance spectroscopy.
    \item \textbf{Chirps or swept-sine signals}: the excitation frequency varies continuously over time. Chirps reduce test duration but require careful processing to avoid leakage and ensure accurate FRF estimation.
    \item \textbf{Multisine signals}: a sum of selected sinusoids with controlled phases, allowing simultaneous probing of many frequencies. They dramatically reduce experiment time and are increasingly used in battery impedance research.
    \item \textbf{Pseudo-random binary sequences (PRBS)}: square-wave signals that approximate white noise over a broad band. They require minimal hardware complexity but require more advanced analysis due to harmonics and nonlinear distortions.
\end{itemize}

In all cases, the amplitude must be large enough to dominate measurement noise but small enough to preserve the “local linearity” required by impedance-based system identification. Because electrochemical systems exhibit state dependence (e.g.\ impedance varies strongly with state of charge), one typically performs excitation around a fixed operating point to ensure local stationarity and allow meaningful linearization.

\section{System identification in the frequency domain}

System identification in the frequency domain aims to construct a mathematical model---equivalent circuit, transfer function or state-space model---that reproduces the observed frequency response function $\hat{H}(\omega)$. The general tasks are:

\begin{itemize}
    \item \textbf{model-structure selection}: choosing between white-, gray- or black-box representations,
    \item \textbf{parameter estimation}: fitting the model to the measured FRF,
    \item \textbf{validation}: verifying that the model captures dynamics without overfitting noise.
\end{itemize}

\subsection{Non-parametric FRF estimation}

Given measured input $u(t)$ and output $y(t)$, the FRF at frequency $\omega$ is estimated as:
\[
\hat{H}(\omega)=\frac{Y(\omega)}{U(\omega)},
\]
where $U(\omega)$ and $Y(\omega)$ are Fourier transforms (or selected-bin DFTs via the Goertzel algorithm). When working with multisines or chirps, cross-spectral methods provide more robust estimates:
\[
\hat{H}(\omega)=\frac{S_{yu}(\omega)}{S_{uu}(\omega)},
\]
with $S_{yu}$ the cross-spectrum and $S_{uu}$ the auto-spectrum of the input. This suppresses contributions from additive noise uncorrelated with the input.

\subsection{Parametric frequency-domain identification}

A parametric model imposes a specific functional form,
\[
G(\omega;\theta),
\]
and the goal is to determine the parameters $\theta$ that minimize the discrepancy with the measured FRF. In electrochemical impedance spectroscopy (EIS), $G(\omega)$ is often an equivalent circuit (e.g.\ $R_s + (R_{ct}\parallel C_{dl}) + Z_W$), a rational function approximation (Black-Box LTI model) or a reduced-order PDE-derived model. Because the impedance is complex-valued, the fitting must capture both magnitude and phase in a statistically consistent manner.

Techniques for rational approximation include:
\begin{itemize}
    \item Sanathanan--Koerner iterative reweighting,
    \item vector fitting, used widely in EIS to obtain stable pole--zero models,
    \item maximum likelihood estimation.
\end{itemize}

These methods provide stable, causal and physically interpretable models.

\section{Parameter estimation}

Parameter estimation finds the parameter vector $\theta$ that best reproduces the measured impedance $\hat{Z}(\omega)$. Under the assumption of additive Gaussian noise, the statistically optimal estimator is the complex weighted least-squares problem:
\[
\min_{\theta} \sum_{\omega} w(\omega)\, \bigl| \hat{Z}(\omega)-G(\omega;\theta) \bigr|^2.
\]
The weights $w(\omega)$ reflect measurement uncertainty, typically higher at high frequencies (quantization noise, stray inductance) and low frequencies (drift and 1/f noise). This cost function corresponds to a maximum-likelihood estimator and yields asymptotically unbiased and efficient parameter estimates.

\subsection{Noise and bias considerations}

Three main sources of bias arise in real measurements:
\begin{itemize}
    \item nonlinear distortion from large perturbation amplitudes,
    \item spectral leakage due to finite-length records,
    \item non-stationarity during measurement (e.g.\ SoC drift).
\end{itemize}

Mitigating these effects requires synchronized sampling, proper windowing, long enough measurement durations and---in batteries---maintaining stable operating conditions.

\section{Model selection and validation}

After fitting, the model must be validated to ensure accuracy, robustness and physical interpretability.

\subsection{Residual analysis}

The residuals
\[
\varepsilon(\omega)=\hat{Z}(\omega)-G(\omega;\theta_{\text{opt}})
\]
should behave like uncorrelated noise. Any structure (e.g.\ systematic bias in the low-frequency arc or non-random phase deviation) indicates missing dynamics or nonlinearities.

\subsection{Identifiability and sensitivity}

Identifiability requires that each model parameter has a distinguishable influence on the FRF. The sensitivity matrix,
\[
S_{ij}=\frac{\partial G(\omega_i;\theta)}{\partial \theta_j},
\]
reveals whether two parameters compensate each other (non-identifiable) or whether their influence is orthogonal. Full column rank indicates local identifiability; near-collinearity signals redundant parameters.

\subsection{Information criteria}

To select among candidate models, information criteria balance fit accuracy against model complexity:

\begin{align}
AIC &= -2\ell + 2k, \\
AIC_c &= AIC + \frac{2k(k+1)}{n-k-1}, \\
BIC &= -2\ell + k\log n, \\
MDL &\approx -\ell + \frac{k}{2}\log n,
\end{align}

where $\ell$ is the log-likelihood, $k$ the number of parameters, and $n$ the number of data points. These criteria penalize over-parameterization and promote parsimony, which is essential for models intended for BMS implementation.

\section{Identification in non-stationary systems}

Electrochemical systems are rarely perfectly stationary: impedance varies with state of charge, temperature, aging, formation processes and even local relaxation dynamics. Thus the classical LTI assumption only holds \emph{locally}.

\subsection{Local linearization and quasi-stationarity}

The most common approach is to assume the system is LTI over short windows (sliding-window EIS). Using the STFT or segmented multi-sine analysis, one extracts a time-varying FRF:
\[
\hat{Z}(\omega,t_k).
\]
This produces time-indexed model parameters such as $R_s(t)$, $R_{ct}(t)$ or Warburg coefficients.

\subsection{Recursive and adaptive identification}

Recursive least-squares (RLS) with exponential forgetting adapts model parameters in real time:
\[
\theta_{k}=\theta_{k-1} + K_k\bigl(z_k - \phi_k^\top \theta_{k-1}\bigr),
\]
where the forgetting factor weights recent measurements more strongly.

Kalman-filter-based parameter tracking similarly estimates $\theta(t)$ while accounting for process noise and drift. These methods underpin real-time impedance tracking and emerging BMS-oriented “dynamic impedance” techniques.

\subsection{LPV and time-varying state-space models}

If a scheduling variable (e.g.\ SoC) is measurable, one may construct a linear-parameter-varying (LPV) model:
\[
\dot{x}=A(\rho(t))x + B(\rho(t))u,
\qquad y=C(\rho(t))x+D(\rho(t))u,
\]
where $\rho(t)$ encodes the drift of operating conditions. LPV models preserve linear structure while capturing global nonlinearity.

\section{Mathematical optimization}

Fitting dynamic models relies fundamentally on mathematical optimization. Three important problem classes arise:

\begin{itemize}
    \item \textbf{Linear least squares}, applicable to simple regression problems or fixed-pole models,
    \item \textbf{Nonlinear least squares}, required for EIS equivalent-circuit models and rational transfer functions,
    \item \textbf{Complex-domain optimization}, necessary when fitting impedance (real and imaginary parts) simultaneously.
\end{itemize}

Because impedance is complex-valued and typically spans several orders of magnitude across frequency, robust solvers (Levenberg--Marquardt, trust-region reflective algorithms, interior-point methods) are essential. Regularization---$L_2$ (ridge) or $L_1$ (sparsity)---helps avoid overfitting and improves stability in ill-conditioned problems.

Optimization is thus the unifying backbone of parametric system identification, enabling the estimation of physically meaningful parameters even in noisy or partially observable electrochemical systems.

\section{Model structures}

A dynamical system may be represented using different levels of abstraction depending on the amount of physical knowledge available and the intended use of the model. In system identification, one distinguishes between three major categories: white-box, gray-box and black-box models. These differ in the balance between physical interpretability, computational complexity and flexibility in representing unknown dynamics.

\subsection{White-box models}

White-box models originate from first principles such as conservation laws, constitutive relations and thermodynamic arguments. In electrochemistry, these include the Butler--Volmer equation, Nernst–Planck transport, and solid-state diffusion PDEs. After spatial discretization, such models naturally lead to high-order ODE or state-space representations. Their parameters have direct physical meaning (diffusion coefficient, exchange current density, transference number, double-layer capacitance), which facilitates interpretation and extrapolation beyond the identification domain. The main limitations are their complexity and the requirement of detailed physical knowledge.

\subsection{Gray-box models}

Gray-box models combine simplified physical structures with empirical components. For electrochemical systems they typically include equivalent-circuit models (ECMs), transmission-line models, or reduced-order PDE-derived models. Their structure embeds physical constraints—positivity, stability and causality—while keeping the number of parameters manageable. Gray-box models are widely used in battery research because they allow incorporation of electrochemical insight (e.g., distinct resistive and capacitive elements, Warburg diffusion) while remaining compatible with efficient estimation algorithms.

\subsection{Black-box models}

Black-box models impose minimal assumptions and are entirely data-driven. Examples include autoregressive models (ARX/ARMAX), rational transfer functions, and neural-network-based representations. They are suitable when the primary goal is accuracy rather than interpretability. In the frequency domain, a black-box representation often takes the form of a stable rational transfer function:
\[
G(s)=\frac{b_0 + b_1 s + \cdots + b_m s^m}{a_0 + a_1 s + \cdots + a_n s^n},
\]
which is fitted directly to the measured FRF. While highly flexible, black-box models require careful validation due to the risk of overfitting and may be difficult to interpret physically.

\section{State-space representations}

State-space models describe dynamical systems in a compact form that is well suited for identification, stability analysis and numerical simulation. A continuous-time linear time-invariant system is expressed as:
\begin{align}
\dot{x}(t) &= A x(t) + B u(t), \\
y(t) &= C x(t) + D u(t),
\end{align}
where $x(t)\in\mathbb{R}^n$ is the state vector, $u(t)$ the input, and $y(t)$ the output. The matrices $(A,B,C,D)$ define the system completely.

\subsection{Relation to transfer functions}

For LTI systems the transfer function and state-space representation are equivalent. The transfer function is obtained as:
\[
G(s)=C(sI-A)^{-1}B + D.
\]
Conversely, any strictly proper rational transfer function admits at least one state-space realization. This equivalence is essential when connecting the PDE-based electrochemical models of the previous chapter to the rational-polynomial impedance models used in identification.

\subsection{Discrete-time representation}

For digital acquisition systems the discrete-time model is:
\begin{align}
x_{k+1} &= A_d x_k + B_d u_k, \\
y_k &= C_d x_k + D_d u_k,
\end{align}
where $A_d=\mathrm{e}^{A T_s}$ and $B_d$ follows from zero-order-hold equivalence. Discrete-time realizations are exploited when estimating models directly from sampled data or implementing real-time algorithms in embedded systems.

\section{Minimal realizations, controllability and observability}

A state-space model may contain redundant states that do not influence the input-output behavior. A \emph{minimal realization} is the representation of smallest possible order that reproduces the exact transfer function.

\subsection{Controllability}

A system is controllable if every state can be reached by a suitable input. The classical test is the rank condition:
\[
\mathrm{rank}\,\mathcal{C} = \mathrm{rank}\,[B\; AB\; A^2B\; \cdots\; A^{n-1}B] = n.
\]
Uncontrollable states cannot be excited and thus do not contribute to the measured impedance; they can be removed without altering the transfer function.

\subsection{Observability}

A system is observable if the initial state can be reconstructed from output measurements. The observability matrix,
\[
\mathcal{O} =
\begin{bmatrix}
C \\ CA \\ CA^2 \\ \vdots \\ CA^{n-1}
\end{bmatrix},
\]
must have full rank $n$. Unobservable states do not appear in the measured voltage; they too can be removed to obtain a minimal realization.

\subsection{Minimal order and electrochemical interpretation}

In electrochemical systems, the minimal order corresponds to the number of dynamically independent physicochemical processes excited by the perturbation—e.g., one state for double-layer charging, one for charge-transfer kinetics, and one or more for diffusion. Equivalent circuits often provide an explicit low-order realization, while PDE discretizations typically produce high-order non-minimal systems that must be reduced.

\section{Model order selection}

Choosing an appropriate model order is crucial for ensuring accuracy without unnecessary complexity.

\subsection{Trade-off between fidelity and robustness}

Low-order models may fail to capture important dynamics (e.g., finite-length diffusion), while high-order models increase variance, slow optimization and risk overfitting. Order selection is guided by:

\begin{itemize}
    \item analysis of the singular values of the Hankel matrix,
    \item inspection of frequency-domain residuals,
    \item information criteria such as AIC, AICc, BIC and MDL,
    \item physical insight into which processes are relevant.
\end{itemize}

For battery impedance, orders between 2 and 6 typically suffice for gray-box ECMs, while black-box rational models may use higher orders if the FRF exhibits strong curvature or multiple arcs.

\section{Model reduction}

High-order systems, such as those obtained from spatial discretization of PDEs, are often reduced to lower-order models that retain essential dynamics.

\subsection{Balanced realization}

A balanced realization diagonalizes both controllability and observability Gramians. States are ranked by their \emph{Hankel singular values} $\sigma_i$, which quantify how strongly each state contributes to the input-output behavior.

\subsection{Balanced truncation}

Balanced truncation retains the states associated with the largest Hankel singular values and discards the rest. The reduced model preserves stability and often guarantees an a priori error bound:
\[
\|G - G_r\|_\infty \leq 2\sum_{i=r+1}^n \sigma_i.
\]
For electrochemical systems this approach enables efficient reduction of diffusion PDEs or high-order transfer-function fits while preserving the dominant time constants.

\subsection{Moment matching and Padé approximation}

Alternative reduction techniques include moment matching, Padé approximations at selected frequencies, and Krylov-subspace methods (Arnoldi). These are especially relevant when approximating the Warburg impedance or finite-length diffusion kernels with low-order rational functions.

\section{Connection to electrochemical models}

The state-space concepts above provide the bridge between the physicochemical models introduced earlier and the rational transfer functions used in identification.

For example, the diffusion equation in a solid particle,
\[
\frac{\partial c}{\partial t} = D \frac{\partial^2 c}{\partial r^2},
\]
can be spatially discretized into a high-order ODE system, linearized around a steady-state concentration profile, and reduced to a low-order state-space model. The resulting transfer function approximates the classical semi-infinite Warburg element or the finite-length diffusion impedance depending on boundary conditions.

Such connections justify the widespread use of rational-polynomial models to represent electrochemical impedance and underpin the identification methods developed in the following chapters.

\section{Relation to transfer functions and rational approximations}

As shown in Part~IV, any stable LTI system with a well-defined impulse response admits a transfer function expressible as a rational function,
\[
G(s) = \frac{b_0 + b_1 s + \cdots + b_m s^m}{a_0 + a_1 s + \cdots + a_n s^n},
\]
when reduced to finite order. Rational transfer functions are automatically KK-consistent because they are analytic for \(\Re(s)>0\).

This property is central in impedance identification for two reasons:

\begin{enumerate}
\item It provides a compact representation of the FRF that satisfies KK relations by construction.
\item It allows one to regularize noisy EIS data by projecting them onto the set of stable causal models.
\end{enumerate}

Thus the rational-polynomial form acts as an implicit KK enforcer, guaranteeing physical admissibility of the result.

\section{Linear time-varying systems}

Many physical systems exhibit dynamics that evolve with time due to slow drifts, environmental changes or internal state evolution. When such variations occur on a time scale that is not negligible with respect to the system dynamics, the linear time-invariant (LTI) approximation becomes insufficient. In such cases the appropriate framework is that of linear time-varying (LTV) systems, described by:
\begin{align}
\dot{x}(t) &= A(t) x(t) + B(t) u(t), \\
y(t) &= C(t) x(t) + D(t) u(t),
\end{align}
where the matrices $(A(t), B(t), C(t), D(t))$ depend explicitly on time.

Unlike LTI systems, LTV systems do not admit a classical transfer function representation. Instead, their behavior is captured by the \emph{time-varying impulse response} $h(t,\tau)$ defined through:
\[
y(t) = \int_{-\infty}^{t} h(t,\tau) \, u(\tau) d\tau.
\]
The kernel $h(t,\tau)$ is not a function of $(t-\tau)$ alone but of both arguments independently, reflecting the explicit time dependence of the system.

\subsection{Fundamental differences between LTI and LTV systems}

The shift from LTI to LTV introduces several important conceptual changes:
\begin{itemize}
\item \textbf{Loss of convolution:} The input-output relation cannot be expressed as $y = h * u$.
\item \textbf{No global transfer function:} There is no $G(s)$ or $G(j\omega)$ valid for all time.
\item \textbf{Time-dependent frequency response:} Local frequency responses can be defined, but they depend on the time at which they are evaluated.
\item \textbf{Loss of classical KK relations:} Kramers--Kronig relations apply only to LTI systems; LTV systems generally violate them.
\end{itemize}

These differences have practical implications for signal design, estimation algorithms and model validation.

\section{Local linearization and short-time LTI approximation}

Despite the absence of a global transfer function, many LTV systems vary slowly enough that they can be approximated as LTI over sufficiently short time intervals. Let $\theta(t)$ be a time-varying parameter (e.g.\ conductivity, rate constant, diffusivity) entering the matrices of the system. If its variation satisfies:
\[
\left| \frac{d\theta(t)}{dt} \right| \ll \frac{1}{T_{\mathrm{dyn}}},
\]
where $T_{\mathrm{dyn}}$ is the dominant time constant of the system, then the system can be considered approximately invariant within a “frozen-time” interval of length $\Delta t$ such that:
\[
\Delta t \ll \left( \frac{d\theta(t)}{dt} \right)^{-1}.
\]

Under this assumption the system behaves as an LTI system with matrices $(A(t_0), B(t_0), C(t_0), D(t_0))$ for all $t \in [t_0 - \Delta t/2,\, t_0 + \Delta t/2]$. This leads to the notion of the \emph{short-time transfer function}:
\[
G(s; t_0) = C(t_0) (sI - A(t_0))^{-1} B(t_0) + D(t_0).
\]

\subsection{Local Taylor expansion of the dynamics}

The state transition of an LTV system can be expanded locally using a Taylor series:
\[
A(t) = A(t_0) + \dot{A}(t_0)(t - t_0) + \mathcal{O}\!\left((t-t_0)^2\right).
\]
If the first-order term is small over the interval of interest, the LTI approximation is valid. Quantifying this approximation is essential for dynamic FRF estimation.
